Sorting Visualizer

📌 Overview

Sorting Visualizer is a web-based tool that helps users understand sorting algorithms through interactive visualizations. The animations allow users to observe how elements are compared, swapped, and sorted step by step.
✨ Features

    Multiple Sorting Algorithms: Bubble Sort, Selection Sort, and Insertion Sort
    Interactive Controls: Start, Pause, and Resume sorting anytime
    Adjustable Speed: Modify sorting speed for better understanding
    Real-time Visual Indications: Highlights comparisons, swaps, and sorted elements
    Mobile-Friendly: Fully responsive design for all devices

🎥 How It Works

    Choose a Sorting Algorithm from the dropdown menu.
    Select Array Size and Speed using the controls.
    Click the Start button to begin sorting.
    Watch how elements are compared, swapped, and sorted with visual indications.
    Use the Pause/Resume button to control the animation.

📚 Sorting Algorithms Explained
🔹 Bubble Sort

    Compares adjacent elements and swaps them if they are out of order.
    The largest elements "bubble up" to their correct position in each pass.
    Time Complexity: O(n²)

🔹 Selection Sort

    Finds the smallest element in the array and swaps it with the first element.
    Repeats the process for the remaining unsorted part.
    Time Complexity: O(n²)

🔹 Insertion Sort

    Builds a sorted list by picking elements and placing them in the correct position.
    Works well for small or nearly sorted arrays.
    Time Complexity: O(n²)
